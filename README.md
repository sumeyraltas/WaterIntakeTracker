# AquaTrack - Günlük Su İçme Takip Uygulaması
Profesyonel endüstriyel tasarım odaklı Android su takip uygulaması.

## Kullanılan Teknolojiler
- **Dil**: Kotlin 2.0+
- **UI**: Jetpack Compose (Material Design 3)
- **Mimari**: MVVM + Repository Pattern
- **Veritabanı**: Room Database + DataStore Preferences
- **Dependency Injection**: Hilt
- **Periyodik Bildirim**: WorkManager
- **Widget**: Android Jetpack Glance Widget
- **Grafik / Dalga**: Custom Compose Canvas Liquid Wave Animation

## Android Studio'da Çalıştırma
1. Bu ZIP arşivini klasöre çıkarın.
2. Android Studio (Ladybug veya üstü) açın.
3. "Open" diyerek bu klasörü seçin.
4. Gradle sync tamamlandıktan sonra "Run 'app'" butonuna basın!
